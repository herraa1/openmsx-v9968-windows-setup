# リリースノート — 0.7.1

[ホーム](../README.ja.md)

Scene 3の描画結果を維持しながら処理を高速化しました。セットアップと起動の手順は変わりません。

- 固定したopenMSX派生版のアニメーションありFULLモードで、**Z80は6.43→10.07 FPS、R800は8.24→12.31 FPS**に向上しました（各15秒を3回測定）。アニメーションの進行速度は維持しています。
- 変形前の画面を再利用し、前の立体の範囲だけを復元。水面転送とメッシュ矩形の統合、コマンド出力処理の改善で描画負荷を削減しました。
- 最適化した比較用ROM、更新したプレビューGIF、詳細な日英PDFを収録。従来の基準ROMとその測定値は区別して保持しています。
- メッシュ・残光・水面のコマンド出力をC実装に切り替える開発用機能を追加し、両機種でアセンブラ実装との画素比較を行いました。
- PROBEをRevision 2へ更新し、LRMMとR20の互換性診断を詳細化しました。FPGA実機での再試験は未実施です。
- 水面データの範囲・全面被覆検査と、今回の実行結果だけを参照するキャプチャ試験を整備しました。

ReleaseのAssetsから `openmsx-v9968-windows-setup-0.7.1.zip` を取得し、同期フォルダ外の新しい書き込み可能なフォルダへZIP全体を展開してください。対応するsetup BAT、続いてデモ起動BATを実行します。既存環境は別フォルダに保持してください。セットアップは上書きしません。

FPSはエミュレーターでの測定値であり、FPGA実機の性能を保証するものではありません。C参照実装は描画動作を確認するもので、命令単位の所要時間は一致しません。FS-A1GTでは所有するBIOSが必要です。C-BIOSは実機BIOS不要です。BIOSやエミュレーター実行ファイルは同梱していません。
